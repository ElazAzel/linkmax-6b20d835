# Project Skills

Each `SKILL.md` is a short, reusable procedure for a LinkMAX domain. Use the skill that matches the changed contract, then use the canonical documentation and code as the source of truth.

| Skill | Use for |
|---|---|
| `react` | React routes, components, client state, i18n, and UI behavior. |
| `supabase` | Schema, RLS, RPC, Storage, Auth, and Edge Functions. |
| `testing` | Unit, integration, browser, and release verification. |
| `devops` | CI/CD, environment variables, migrations, worker deployment, and incident triage. |
| `analytics`, `business-zone`, `calendar`, `payments` | Domain-specific behavior. |
| `communications`, `content-creation`, `design-brand`, `file-management`, `changelog` | Supporting workflows. |

Maintain a skill when its command, location, owning service, security boundary, or verification procedure changes. Skills are instructions, not proof that a feature is live.
