# Content Creation

Use for public-page content, block templates, media, or localized copy.

1. Keep content structured in its intended block model rather than embedding unsafe markup.
2. Localize user-visible product strings through the i18n system.
3. Validate links, media ownership, accessible labels, and mobile layout.
4. Sanitize rich text and never publish private account data in templates.
