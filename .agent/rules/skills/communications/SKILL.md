# Communications

Use for notices, incident updates, support templates, and release communication.

1. State verified facts, user impact, next action, and time reference.
2. Avoid credentials, personal data, speculative root causes, and unverified promises.
3. Use the product's supported languages and link users to the relevant action.
4. Route security disclosures through the private security contact.
