# Design and Brand

Use for visual changes to product UI or public templates.

1. Start from the existing component and token system.
2. Use accessible contrast, visible focus, semantic controls, and responsive constraints.
3. Use familiar icons for compact actions and avoid text-only tool buttons where an existing icon exists.
4. Verify desktop and mobile states with an actual browser screenshot when layout changes.
5. Do not represent mock data, unsupported pricing, or unapproved brands as live product behavior.
