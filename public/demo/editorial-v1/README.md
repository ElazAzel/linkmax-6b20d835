# Landing editorial photography

Nine original images generated with the built-in OpenAI Imagegen tool on
2026-10-21 for the fictional Aruzhan Nails, Dana English and Timur Shot examples.
The people, businesses and scenes are illustrative, not customer endorsements.

Art direction: direct flash, cherry and chrome beauty details on lavender;
cobalt and lime learning scenes; charcoal and amber fashion portraits.
The exact prompt for every image is recorded in `sources.json`.

WebP files are served locally. Portraits are 480px; scene images are 960px.
This set is used only by the landing page, leaving starter template photography
independent from its visual direction.
