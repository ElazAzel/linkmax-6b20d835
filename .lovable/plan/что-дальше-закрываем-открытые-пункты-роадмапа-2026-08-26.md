# Что дальше: закрываем открытые пункты роадмапа

Дизайн-трек (фазы 1–10 «Design without a Designer») завершён и задокументирован.
По `docs/product/DETAILED_PHASE_PLAN_2026.md` открытыми остались только два пункта
Фазы 20, оба помечены как частично сделанные.

## Приоритет 1 — Digital Goods: защищённая доставка файлов

Сейчас цифровые товары продаются, но файл отдаётся без защиты.

- Приватный бакет для файлов товаров (загрузка только владельцем страницы).
- Выдача доступа после оплаты: короткоживущая подписанная ссылка вместо
  публичного URL, лимит скачиваний и срок жизни ссылки.
- Таблица выданных доступов (покупка → товар → счётчик скачиваний → срок),
  RLS: покупатель видит только свои записи, владелец — продажи своих товаров.
- Страница «Мои покупки» по ссылке из письма/мессенджера: список файлов и кнопка
  скачивания, которая каждый раз запрашивает свежую подписанную ссылку.
- Владельцу — блок в дашборде: сколько раз скачали, когда истекает доступ.

## Приоритет 2 — AI Financial Advisor (на базе AI Insights)

Расширяем существующие Insights до финансового советника, без нового движка.

- Сводка за период: выручка, комиссии, расходы, средний чек, топ-услуги —
  считается детерминированно из уже существующих данных сделок/платежей.
- Поверх цифр — короткие рекомендации (что поднять в цене, где падает
  конверсия, какие услуги убыточны), с явными «почему» из тех же метрик.
- Одна вкладка внутри Insights, без отдельного раздела в меню.

## Приоритет 3 — верификация роадмапа

- E2E-сценарий «Покупка → комиссия → статус сделки в CRM» (Playwright).
- Интеграционный тест маппинга Custom Fields в JSONB.
- Обновить `DETAILED_PHASE_PLAN_2026.md` и `CHANGELOG.md` по факту.

## Технические детали

- Хранилище: приватный бакет + edge-функция выдачи подписанной ссылки, которая
  проверяет оплату и лимиты. Никаких публичных URL для платных файлов.
- Все новые таблицы public-схемы: `CREATE TABLE` → `GRANT` → RLS → политики.
- Финансовые расчёты — детерминированные (Algorithmic-First); модель Lovable AI
  используется только для формулировки рекомендаций, не для арифметики.
- Все строки локализуются в ru/en/kk/uz, база — русский.
- UI — существующий минималистичный стиль (`border-0 shadow-none`), bottom
  sheets на мобильных.

Начинать предлагаю с Приоритета 1 — он напрямую защищает деньги и контент
пользователей. Скажи, если порядок нужно поменять.
