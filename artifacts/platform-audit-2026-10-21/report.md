# Проверка LinkMAX — 21 октября 2026

## Исправлено

- Обложка: добавлено перемещение мышью и касанием, точная настройка по двум осям и сброс к центру. Позиция хранится в `coverPosition` блока профиля и используется в публичной странице, быстром редакторе, полном редакторе и мастере профиля. Старые обложки остаются по центру; некорректные значения ограничиваются безопасным диапазоном, `null` обрабатывается как отсутствие настройки.
- Высота обложки в быстром редакторе теперь совпадает с публичной страницей, включая размер XL. Кнопки настроек видны и без наведения мыши.
- Превью перемещения масштабируется с сохранением пропорций реального блока на холсте; узкое окно настроек больше не меняет направление кадрирования. Независимое ревью подтвердило устранение этой проблемы.
- Бизнес-инструменты: переключение работает в текущей вкладке даже при заблокированном localStorage. Скрытие бизнес-разделов и доступность событий/заявок для обычных страниц сохранены.
- Админка переводов: вместо пустой страницы посетитель без административного доступа перенаправляется на вход.
- Административный редактор шаблонов: проверка роли выполняется до монтирования редактора и загрузки данных шаблона.
- Добавлены переводы управления обложкой для русского, английского, казахского и узбекского. В узбекском кабинете заполнены три отсутствовавшие подсказки.
- Тестовая конфигурация использует единственный React 19 для библиотек, которым локальная установка pnpm подставляла React 18. Обновлены проверки навигации событий и smoke-тест после перехода с Vite-контейнера `#root` на документ TanStack Start.

## Границы проверки

- В этой сессии нет E2E-учётной записи с административной ролью. Изменение пользователей, тарифов, переводов и шаблонов под реальным администратором не выполнялось.
- Настоящие платежи, возвраты, внешние уведомления, cron и вебхуки не запускались. Автоматические проверки бизнес-логики и SQL не заменяют тестовую оплату у провайдера.
- Локальный dev-сервер Vite выдавал тайм-ауты загрузки серверных модулей, в том числе `crossws`. Браузерная проверка выполнена через успешно собранный production Node-сервер. Причина зависания dev-запуска в этой Windows-среде остаётся не устранена.
- Исправления находятся в рабочей копии; публикация и применение миграций в рабочей базе не выполнялись. Для этих исправлений новые миграции не нужны.

## Повторение проверок

Использовался предоставленный средой Node.js, поскольку `npm` отсутствует в PATH оболочки. Для полной проверки запускался `vitest run --pool=threads`, для SQL — `node --test "src/services/__tests__/*.sql.test.mjs"`, для скриптов — `node --test "scripts/__tests__/*.test.mjs"`.

Временная конфигурация `tmp/platform.playwright.config.ts` запускает `.output/server/index.mjs` на `127.0.0.1:8080` и использует установленный Chrome. Браузерный прогон выполнен после `vite build --config vite.standalone.config.ts` с локальным `VITE_APP_DOMAIN`. Временные журналы лежат в `tmp-platform-*.log`.
