## Что Korner делает лучше всего

1. Одна визуальная система: фон `#F5F5F7`, белые карточки без рамок, скругление 16–30px,
   почти невидимая тень, чёрный текст. Цвет приносит только контент (фото, обложки).
2. Мало типов блоков, но выразительных: шапка с обложкой, карточка «текст + фото + кнопка»,
   сетка плиток-картинок.
3. Никаких управляющих элементов поверх контента.

## Блокеры вне кода

1. **Миграция `20261016120000_korner_card_tiles.sql` не применена.** Базой управляет Lovable
   Cloud, GitHub-деплой миграции пропускает (нет секретов). «Карточка» и «Плитки» скрыты
   в шторке до `VITE_LINKMAX_SHOWCASE_BLOCKS=true`. Промпт для Lovable:
   «Примени миграцию supabase/migrations/20261016120000_korner_card_tiles.sql к базе и
   добавь VITE_LINKMAX_SHOWCASE_BLOCKS=true в переменные окружения».
2. `bun.lock` ссылается на приватный npm-кэш Lovable для двух пакетов: вне Lovable/GitHub
   `bun install --frozen-lockfile` падает.
