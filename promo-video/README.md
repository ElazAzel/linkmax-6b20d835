# LinkMAX — промо-ролик (Remotion)

Вертикальный ролик 1080×1920, 30 fps, 36 секунд, для Reels, TikTok и Shorts. Звук идёт в комплекте.

## Запуск

```bash
cd promo-video
npm ci
npm run studio   # превью в браузере, перед стартом генерирует звук
npm run render   # → out/linkmax-promo.mp4
npm run still    # постер → out/poster.png
```

Если Remotion не может скачать Chromium (закрытая сеть, CI), укажите путь к уже установленному браузеру:
`npm run render -- --browser-executable=/path/to/chrome`.

## Сценарий

| Кадры | Время | Сцена | Смысл |
|---|---|---|---|
| 0–120 | 0–4 с | Hook | Клиенты пишут в директ и уходят без ответа |
| 120–210 | 4–7 с | Brand | LinkMAX: одна ссылка, по которой клиент выбирает, записывается и платит |
| 210–360 | 7–12 с | AI Builder | Страница мастера собирается по промпту |
| 360–480 | 12–16 с | Booking | Запись без переписки, напоминание |
| 480–600 | 16–20 с | Payment | Предоплата через Kaspi или картой, меньше неявок |
| 600–720 | 20–24 с | CRM | Уведомления в Telegram и воронка клиентов |
| 720–810 | 24–27 с | Analytics | Видно, откуда приходят клиенты |
| 810–900 | 27–30 с | Niches | Для кого продукт |
| 900–1080 | 30–36 с | CTA | lnkmx.my/ваше-имя, бесплатный старт |

## Звук

`scripts/generate-audio.mjs` синтезирует всю звуковую дорожку кодом, без сэмплов и чужой музыки, поэтому лицензии не нужны:

- `music.wav`: трек на 120 BPM. В хуке тикают часы, на 4-й секунде дроп, на 28-й брейкдаун с райзером, на 30-й удар под CTA.
- SFX: `pop`, `click`, `whoosh`, `ding`, `success`, `cash`.

Одна доля — 15 кадров, один такт — 60, поэтому все склейки попадают в бит. SFX привязаны к тем же константам, что и анимации (`BLOCK_TIMES`, `DAY_TAP`, `PAID_AT` и т. д.), см. `src/Promo.tsx`. Если сдвигаете анимацию, звук сдвинется вместе с ней.

WAV-файлы не хранятся в git. Генерация детерминированная, их пересоздают `npm run studio` и `npm run render`.

## Что поменять под себя

- Тексты сцен лежат в `src/scenes/*.tsx`, цвета и шрифт в `src/theme.ts`.
- Чтобы добавить закадровый голос, положите `public/audio/voiceover.mp3` и добавьте `<Audio>` в `src/Promo.tsx`. Громкость музыки при этом лучше опустить до ~0.5.
- Все данные в демо вымышленные: мастер «Айгерим», цены, клиенты. Графики в сцене аналитики намеренно показаны без чисел.
